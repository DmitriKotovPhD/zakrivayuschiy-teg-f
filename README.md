Результат онлайн: https://dmitrikotovphd.github.io/zakrivayuschiy-teg-f/

## Основная область интерфейса:
- Набор карточек с описанием основных вех модуля вёрстки.

## Шапка:
- Надпись для привлечения внимания

## Подвал:
